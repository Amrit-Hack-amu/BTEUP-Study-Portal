Level 1 – Basics: Network Security Fundamentals

LEVEL 1 – BASIC

1.1 What is a network?

A network is a group of computers, phones, servers and printers connected to share data. Example: your college lab computers connected by a switch and connected to the Internet by a router.

Hinglish

Network matlab bahut saare computers ka aapas mein judna taaki data share ho sake.

1.2 What is Network Security?

Definition

Network security is the set of tools, rules and practices that protect a network and its data from unauthorized access, misuse, attacks and data theft.

Hinglish

Network security ka matlab hai network aur uske data ko chor, hacker, virus aur galat use se bachana.

Remember the 3 goals (CIA): Confidentiality (only allowed people see data), Integrity (data is not changed), Availability (service is always working).

1.3 What is a Network Security Product?

Definition

A network security product is a hardware device or software program that is placed in or around a network to monitor, filter, control or protect network traffic.

Hinglish

Network security product ek device ya software hota hai jo network ke traffic ko dekhta, rokta aur check karta hai.

1.4 Why do organizations use security devices?

  • Stop attackers – block hackers from entering the internal network.
  • Protect data – customer records, bank details, exam results.
  • Stop malware – virus, ransomware, worms.
  • Follow rules – laws and company policies need security controls.
  • Keep services running – avoid downtime because of attacks.
  • Safe remote work – employees connect from home securely.

1.5 Five products in one line each

ProductOne-line meaningEveryday analogy
FirewallAllows or blocks traffic using rules.Security guard at the main gate checking the entry list.
IDSWatches traffic and raises an alarm on suspicious activity.CCTV camera + burglar alarm. It only alerts.
IPSWatches traffic and automatically blocks attacks.Guard who sees a thief and stops him immediately.
VPN ConcentratorDevice that creates many secure encrypted tunnels for remote users.A private covered tunnel from your home to the office.

Hinglish

Firewall = gate guard (rules se rokta hai). IDS = CCTV (sirf alarm bajata hai). IPS = guard jo chor ko pakad leta hai. VPN concentrator = office tak private tunnel. Content gateway = bag scanner jo kharab content pakadta hai.

Real-life picture: College

Your college has one Internet line. Firewall protects the entry. IDS/IPS watches for attacks. Content gateway blocks adult and malware websites in the lab. VPN lets teachers open college server from home.

Basic terms you must know (click)
  • Packet – small piece of data travelling in a network.
  • IP address – address of a device. Port – door number of a service (HTTP 80, HTTPS 443, SSH 22).
  • Traffic – data moving in the network. Inbound = coming in. Outbound = going out.
  • LAN – local network (trusted). WAN/Internet – outside network (untrusted).
  • Malware – harmful software. Intrusion – unauthorized entry. Threat – possible danger. Vulnerability – weakness.
  • Encryption – converting data into unreadable form. Authentication – proving who you are.

Q. What is a network security product?
A network security product is a hardware or software tool used to protect a network by monitoring, filtering and controlling traffic. Examples: firewall, IDS, IPS, VPN concentrator and content screening gateway.

A. Firewall

🟢 OFFICIAL SYLLABUS LEVEL 2 – EXAM LEVEL

A.1 Definition and purpose

Definition

A firewall is a network security device or software that monitors incoming and outgoing network traffic and allows or blocks it according to a set of security rules. It sits between a trusted network (LAN) and an untrusted network (Internet).

Hinglish

Firewall ek aisa guard hai jo network ke darwaze par baitha hai. Wo har aane-jaane wale packet ko rules ki list se check karta hai. Rule allow kare to jaane deta hai, nahi to rok deta hai.

Purpose: (1) control access, (2) block attacks, (3) hide internal network, (4) log traffic, (5) enforce company policy.

A.2 Why is a firewall required?

  • Internet has hackers, bots and malware. Without a firewall every system is open to them.
  • Many services (like Telnet or file sharing) should never be reachable from outside.
  • It gives one central place to apply security rules instead of setting every computer separately.
  • It keeps a record (log) of who tried to connect, useful for investigation.
Real-life example

A house has a main door lock. Without it anyone can walk in. Firewall is the lock plus guard for your network.

A.3 How a firewall works (step by step)

  1. A packet arrives at the firewall (from LAN or Internet).
  2. Firewall reads packet details: source IP, destination IP, port, protocol (TCP/UDP/ICMP).
  3. It compares these details with the rule list from top to bottom.
  4. First matching rule is applied: Allow, Deny (drop) or Reject.
  5. If no rule matches, the default rule is applied (best practice: deny all).
  6. The decision is written in the log.
Hinglish

Packet aata hai, firewall uska IP, port aur protocol padhta hai, rule list se match karta hai, allow ya deny karta hai. Koi rule match na ho to default deny lagta hai. Isko "Default Deny" kehte hain aur yeh sabse safe tarika hai.

Diagram 1: Firewall between LAN and Internet

Explanation: All traffic between Internet and LAN must pass through the firewall. Allowed packets (green line) go inside. Bad packets (red line) are dropped.

Hinglish

Internet aur LAN ke beech firewall lagta hai. Har packet firewall se hokar jaata hai. Sahi packet andar jaata hai, kharab packet wahin rok diya jaata hai.

A.4 Types of firewall

1) Packet Filtering Firewall (Network layer, Layer 3-4)

Definition

A packet filtering firewall checks every packet separately using source IP, destination IP, source/destination port and protocol, and then allows or blocks it using an Access Control List (ACL).

Hinglish

Yeh sabse simple firewall hai. Har packet ko alag-alag check karta hai, pichle packet ko yaad nahi rakhta. Isliye ise "stateless" bhi kehte hain.

RuleSourceDestinationPort/ProtocolAction
1AnyWeb serverTCP 80, 443Allow
2AnyAnyTCP 23 (Telnet)Deny
3AnyAnyAnyDeny (default)

Advantages: fast, cheap, simple. Disadvantages: does not understand connection state or application data; can be fooled by IP spoofing and fragmented packets.

2) Stateful Inspection Firewall

Definition

A stateful inspection firewall tracks the state of every active connection (for example TCP handshake) in a state table and allows only those packets that belong to a valid, established connection.

Hinglish

Yeh firewall yaad rakhta hai ki kaun si connection chal rahi hai. Agar andar se kisi ne request bheji hai, to uska reply allow hoga. Bina request ke bahar se aaya reply block ho jaata hai.

Example

You open google.com from your PC. Firewall notes this connection in its state table. Google's reply is allowed because it matches the entry. If a stranger sends a random reply packet with no matching entry, it is dropped.

State table entry: source IP, destination IP, ports, protocol, connection state (NEW, ESTABLISHED, CLOSING), timeout.

Advantages: more secure than packet filter, understands connections. Disadvantages: needs more memory and CPU; cannot read deep application content.

3) Application-Level Firewall / Proxy Firewall (Layer 7)

Definition

An application-level (proxy) firewall acts as a middleman between user and server. It receives the request, inspects the application data (HTTP, FTP, SMTP), and then creates a new separate request to the destination on behalf of the user.

Hinglish

Proxy firewall beech mein "darmiyaan wala" ban jaata hai. User seedha server se baat nahi karta. Proxy request ko andar tak padhta hai (jaise website ka URL, command) aur phir khud server se connect karta hai.

Advantages: deep checking, hides internal IPs, content filtering, detailed logs. Disadvantages: slower, needs one proxy per application, costly.

4) Circuit-Level Gateway (Layer 5, Session layer)

Definition

A circuit-level gateway monitors the TCP handshake and session setup between two hosts to decide if the session is legitimate. After the session is approved, it forwards the data without checking the content.

Hinglish

Yeh sirf dekhta hai ki connection (circuit) sahi tarike se bani ya nahi (TCP handshake). Ek baar connection ok ho gayi, to andar ka data nahi padhta. SOCKS isi type ka example hai.

Advantages: fast, hides internal network. Disadvantages: cannot detect malware inside the allowed session.

5) Next-Generation Firewall (NGFW)

Definition

A Next-Generation Firewall combines traditional stateful firewall with deep packet inspection, application awareness, integrated IPS, user identity control and threat intelligence.

Hinglish

NGFW purane firewall ka smart version hai. Yeh sirf IP aur port nahi dekhta, balki yeh bhi pehchanta hai ki kaun si application (WhatsApp, YouTube) chal rahi hai aur kaun user hai. Iske andar IPS bhi hota hai. Advanced detail Level 3 mein hai.

A.5 Hardware firewall vs software firewall

Hardware firewall: a dedicated physical box (e.g. Cisco ASA, Fortinet FortiGate, Palo Alto) that protects the whole network. Software firewall: a program installed on one computer (e.g. Windows Defender Firewall, iptables on Linux) that protects only that computer. Detailed table is in Section "11 Comparison Tables".

A.6 Firewall rules, policies and access control

  • Rule: one instruction, for example "Allow TCP 443 from Any to Web server".
  • Policy (Security policy): the full set of rules based on company needs.
  • ACL (Access Control List): ordered list of allow/deny rules.
  • Default Deny: block everything that is not clearly allowed (secure approach).
  • Default Allow: allow everything that is not blocked (risky approach).
  • Principle of least privilege: give only the minimum access needed.
  • Rule order matters: first match wins, so specific rules go before general ones.
  • Inbound rules control traffic coming in; outbound rules control traffic going out.
Example policy for a college

Allow students: HTTP/HTTPS only. Allow staff: HTTP, HTTPS, SSH to servers. Deny: all P2P and Telnet. Deny: everything else.

A.7 Firewall architecture and placement

  • Perimeter firewall: at the border between Internet and LAN (most common).
  • Internal firewall: between internal departments (e.g. HR network and student network).
  • Host firewall: on each computer.
  • Screened subnet (DMZ) architecture: public servers are placed in a separate zone (see below).
  • Dual firewall: one firewall in front of DMZ and another behind it for extra safety.

A.8 DMZ (Demilitarized Zone) and firewall

Definition

A DMZ is a separate small network zone between the Internet and the internal LAN, where public-facing servers (web, mail, DNS) are kept. The firewall controls traffic between Internet, DMZ and LAN.

Hinglish

DMZ ek "beech ka zone" hai. Website ya mail server ko public ko dikhana padta hai, isliye unhe andar ke private network mein nahi rakhte. Agar hacker DMZ ke server ko hack kar bhi le, to wo seedha aapke LAN tak nahi pahunch paata.

Real-life example

Bank has a reception hall (DMZ) where public can come. The vault and staff offices (LAN) are behind another locked door.

Typical rules: Internet → DMZ: only web (80/443) and mail allowed. Internet → LAN: denied. LAN → DMZ: allowed for management. DMZ → LAN: denied (or very limited).

Diagram 2: Firewall with DMZ architecture

Explanation: The firewall has three zones: Internet (outside), DMZ (public servers) and LAN (private). Public users can reach only the DMZ servers. LAN is hidden.

Hinglish

Firewall ke teen hisse hain: bahar ka Internet, beech ka DMZ aur andar ka LAN. Public sirf DMZ ke web/mail server tak pahunch sakta hai. LAN safe rehta hai.

A.9 Advantages, disadvantages and limitations

✔ Advantages
  • Blocks unauthorized access
  • Central control of rules
  • Hides internal IP addresses (NAT)
  • Keeps logs for audit
  • Enforces company policy
✖ Disadvantages / Limitations
  • Cannot stop attacks from inside (insider threat)
  • Cannot stop traffic that does not pass through it
  • Cannot fully stop viruses inside allowed files
  • Wrong rules create holes or block good traffic
  • Can slow the network; needs regular updates
  • Cannot protect from social engineering/phishing alone

A.10 Real-world examples

  • Hardware: Cisco ASA / Firepower, Fortinet FortiGate, Palo Alto Networks, pfSense.
  • Software: Windows Defender Firewall, Linux iptables / nftables / UFW, ZoneAlarm.
  • Home Wi-Fi router has a small built-in firewall (NAT + packet filter).
Keywords: packet, ACL, rule, default deny, stateful, state table, proxy, circuit-level, NGFW, DMZ, perimeter, trusted/untrusted, NAT, inbound/outbound.

B. IDS – Intrusion Detection System

🟢 OFFICIAL SYLLABUS LEVEL 2 – EXAM LEVEL

B.1 Definition and purpose

Definition

An Intrusion Detection System (IDS) is a security tool that monitors network traffic or system activity, detects suspicious or malicious behaviour, and sends an alert to the administrator. It only detects and reports; it does not block by itself.

Hinglish

IDS ek CCTV camera aur alarm jaisa hai. Wo network ko dekhta rehta hai. Kuch galat dikhe to admin ko alert bhejta hai. Lekin attack ko khud rokta nahi (passive).

Purpose: detect attacks early, collect evidence, support investigation, find policy violations.

B.2 Working mechanism (step by step)

  1. Collect: IDS sensor copies network traffic (using a SPAN/mirror port or network TAP) or reads host logs.
  2. Analyze: traffic is compared with attack signatures or with a normal-behaviour profile.
  3. Detect: if a match or abnormal behaviour is found, an event is created.
  4. Alert: alert is sent by email, SMS or to a dashboard/SIEM.
  5. Log: details are stored for investigation.
  6. Respond: the administrator decides what action to take (block IP, patch system).
Hinglish

Pehle traffic ki copy li jaati hai, phir analysis hota hai, suspicious mile to alert aata hai, log save hota hai, aur admin action leta hai.

Diagram 3: IDS monitoring network traffic

Explanation: IDS gets only a copy of the traffic. Real traffic keeps flowing, so IDS cannot block it. It sends an alert to the administrator.

Hinglish

IDS traffic ki sirf copy dekhta hai. Asli traffic nahi rukta. Isliye IDS sirf alert deta hai, block nahi karta.

B.3 Types of IDS by location

1) Network-based IDS (NIDS)

Definition

A NIDS is placed at key points in the network and monitors the traffic of all devices on that network segment.

Hinglish

NIDS poore network ka traffic dekhta hai, jaise ek CCTV jo poori building ka gate dekhta hai. Example: Snort, Suricata, Zeek.

Pros: one sensor covers many devices; does not affect host performance. Cons: cannot read encrypted traffic; can miss attacks on very busy links; does not see what happens inside a single host.

2) Host-based IDS (HIDS)

Definition

A HIDS is installed on a single computer or server and monitors system logs, file changes, running processes and local activity of that host.

Hinglish

HIDS ek hi computer ke andar baitha hai. Wo dekhta hai ki koi important file to nahi badli, koi unknown program to nahi chala. Example: OSSEC, Wazuh, Tripwire.

Pros: sees inside the host, can read decrypted data, detects file tampering. Cons: must be installed on every host; uses host CPU/memory; if host is hacked, HIDS can be disabled.

B.4 Detection methods

1) Signature-based detection (misuse detection)

Definition

Signature-based detection compares traffic with a database of known attack patterns (signatures). If a pattern matches, an alert is raised.

Hinglish

Jaise police ke paas chor ki photo (signature) hoti hai. Photo se match hua to pakad liya. Jo chor naya hai aur photo nahi hai, wo nahi pakda jaayega.

Pros: accurate for known attacks, few false alarms. Cons: cannot detect new attacks (zero-day); database must be updated often.

2) Anomaly-based detection (behaviour-based)

Definition

Anomaly-based detection first learns what normal network behaviour looks like (a baseline). Any big deviation from this baseline is treated as suspicious.

Hinglish

System pehle normal behaviour seekhta hai. Agar raat ke 3 baje achanak 10 GB data bahar ja raha ho, to ye normal nahi hai, alert aa jaayega.

Pros: can detect new/unknown attacks. Cons: more false positives; needs a learning period; baseline can be poisoned by attacker.

Also remember: False positive = harmless activity wrongly flagged. False negative = real attack missed (more dangerous). Hybrid IDS uses both signature and anomaly methods.

B.5 Advantages, disadvantages and limitations

✔ Advantages
  • Detects attacks that pass the firewall
  • Gives early warning
  • Provides logs and evidence
  • Does not slow traffic (passive)
  • Finds policy violations
✖ Disadvantages / Limitations
  • Does not stop the attack
  • False positives need manual work
  • Needs expert admin to read alerts
  • Cannot inspect encrypted traffic (NIDS)
  • Signature database must be updated

B.6 Real-world examples

  • Snort and Suricata (open-source NIDS), Zeek (network analysis), OSSEC / Wazuh (HIDS), Tripwire (file integrity).
  • A college server room has Snort. At midnight it detects a port scan from one IP and emails the admin.

B.7 IDS vs Firewall

Firewall = prevents access using rules (gate guard). IDS = detects and alerts (CCTV). They work together. Full table is in "11 Comparison Tables".

Keywords: sensor, SPAN/mirror port, TAP, signature, anomaly, baseline, alert, false positive, false negative, passive, NIDS, HIDS, log, zero-day.

C. IPS – Intrusion Prevention System

🟢 OFFICIAL SYLLABUS LEVEL 2 – EXAM LEVEL

C.1 Definition and purpose

Definition

An Intrusion Prevention System (IPS) is a security device or software placed in-line in the network path that inspects traffic, detects malicious activity and automatically blocks or stops it in real time.

Hinglish

IPS wo guard hai jo sirf alarm nahi bajata, balki chor ko turant pakad bhi leta hai. IDS sirf dekhta hai, IPS dekhta bhi hai aur rokta bhi hai. IPS traffic ke raaste ke beech mein (in-line) lagta hai.

Purpose: stop attacks before they reach the target, reduce admin workload, give automatic protection.

C.2 How IPS works (step by step)

  1. All traffic passes through the IPS (in-line placement).
  2. IPS inspects each packet and session (headers + payload).
  3. It uses detection methods: signature, anomaly, policy and reputation.
  4. If traffic is clean, it is forwarded to the destination.
  5. If traffic is malicious, IPS takes action: drop packet, block source IP, reset connection or quarantine.
  6. IPS logs the event and alerts the administrator.
Hinglish

Traffic IPS ke andar se hokar guzarta hai. Saaf hai to aage jaata hai. Kharab hai to IPS use drop kar deta hai, IP block kar deta hai ya connection tod deta hai. Phir log aur alert bhi banata hai.

Diagram 4: IPS blocking malicious traffic

Explanation: Unlike IDS, the IPS sits directly in the path. Clean traffic passes (green). Malicious traffic (red) is dropped and logged.

Hinglish

IPS raaste ke beech mein hai, isliye har packet usi se guzarta hai. Bura packet wahin ruk jaata hai.

C.3 Types of IPS

1) Network-based IPS (NIPS)

Definition

A NIPS is placed in-line on a network link (usually behind the firewall) and inspects and blocks malicious traffic for all devices behind it.

Hinglish

NIPS network ke entry point par lagta hai aur poore network ko protect karta hai. Example: Cisco Firepower, Palo Alto Threat Prevention, Snort in inline mode.

2) Host-based IPS (HIPS)

Definition

A HIPS is software installed on one computer that monitors and blocks dangerous activity on that host, such as unknown program execution or changes to system files.

Hinglish

HIPS ek computer ke andar chalta hai aur wahi ke khatarnak program ya file change ko rokta hai. Example: endpoint security software with HIPS module, Symantec/McAfee HIPS.

C.4 Detection and prevention techniques

TechniqueSimple meaning
Signature-basedMatches known attack patterns.
Anomaly-basedDetects behaviour different from normal.
Policy-basedBlocks anything that breaks a written policy (e.g. no FTP).
Reputation-basedBlocks IPs/domains known to be bad.
Protocol analysisChecks that protocol follows its standard rules.

C.5 How IPS blocks malicious traffic (actions)

  • Drop the bad packet silently.
  • Block the attacker's IP address for some time.
  • Reset the TCP connection (send RST).
  • Rate limit – slow down flood traffic (DoS).
  • Quarantine the infected host (mostly HIPS).
  • Alert and log the event.
Example

An attacker tries SQL injection on your website. IPS sees the SQL pattern in the HTTP request, drops the packet and blocks the attacker's IP for 1 hour. The website never receives the attack.

C.6 Advantages, disadvantages and limitations

✔ Advantages
  • Automatic real-time blocking
  • Stops attacks before damage
  • Reduces admin work
  • Protects unpatched systems (virtual patching)
  • Logs and reports
✖ Disadvantages / Limitations
  • False positives can block real users
  • In-line device can become a single point of failure
  • Can add small delay (latency)
  • Expensive; needs tuning and updates
  • Cannot read encrypted traffic without SSL inspection

C.7 Real-world examples

  • Cisco Firepower, Palo Alto Networks, Fortinet FortiGate IPS, Snort/Suricata in inline mode, TippingPoint.
  • A bank uses IPS behind its firewall to stop brute-force login attacks on net banking.
Keywords: in-line, prevent, drop, block, reset, rate limit, NIPS, HIPS, signature, anomaly, false positive, real-time, virtual patching.

C.8 IDS vs IPS (short)

IDS: passive, out-of-band (gets a copy), detects and alerts. IPS: active, in-line, detects and blocks. Full table in "11 Comparison Tables".

D. VPN Concentrator

🟢 OFFICIAL SYLLABUS LEVEL 2 – EXAM LEVEL

D.1 What is a VPN?

Definition

VPN (Virtual Private Network) creates a secure, encrypted tunnel over a public network like the Internet, so that data travels privately as if it were on a private network.

Hinglish

VPN Internet ke upar ek private, encrypted surang (tunnel) bana deta hai. Beech mein koi data padh nahi sakta. Jaise bheed wali sadak par aapki apni band gaadi.

D.2 What is a VPN Concentrator?

Definition

A VPN concentrator is a dedicated network device that creates and manages a large number of VPN tunnels at the same time, handling encryption, authentication and secure access for many remote users or sites.

Hinglish

Jab hazaron employees ghar se office ka network use karte hain, to sabke tunnel ek hi device sambhalta hai. Isi device ko VPN concentrator kehte hain. Ye VPN ka "bada control room" hai.

Purpose: give secure remote access to company resources, support many users, centralize VPN policy, offload heavy encryption work.

D.3 How a VPN concentrator works (step by step)

  1. Remote user starts the VPN client software and connects to the concentrator's public IP.
  2. Authentication: user proves identity (username + password, certificate, OTP/MFA).
  3. Both sides agree on encryption method and exchange keys (e.g. IKE in IPsec).
  4. An encrypted tunnel is created.
  5. User's data is encrypted by the client, sent through the Internet, and decrypted by the concentrator.
  6. Concentrator applies access policy and forwards data to internal servers. Replies come back through the same tunnel.
  7. When user disconnects, the tunnel is closed.

Diagram 5: VPN concentrator connecting multiple remote users

Explanation: Many users and a branch office connect over the Internet using encrypted tunnels. The concentrator checks identity, decrypts data and passes it to the company LAN.

Hinglish

Ghar, hotel, mobile aur branch office, sab alag-alag tunnel se concentrator tak aate hain. Concentrator pehchaan check karta hai, data decrypt karta hai aur company ke LAN tak pahunchata hai.

D.4 Role of encryption and authentication

  • Encryption keeps data secret (confidentiality). Example algorithms: AES, 3DES.
  • Authentication checks who is connecting. Methods: password, digital certificate, pre-shared key, OTP / multi-factor, RADIUS server.
  • Integrity check (hash, e.g. SHA) makes sure data was not changed on the way.
Hinglish

Encryption data ko chhupata hai, authentication batata hai ki aap kaun ho, aur integrity check batata hai ki data raste mein badla nahi.

D.5 Types of VPN

Remote-access VPN

One user connects to the company network using VPN client software from anywhere. Example: a teacher opens the college server from home. The VPN concentrator is the usual endpoint.

Site-to-site VPN

Two whole networks are connected permanently using VPN gateways. Example: bank head office and branch office share one secure network over the Internet.

Hinglish

Remote-access = ek insaan ka ghar se office. Site-to-site = poore office ka doosre office se permanent connection.

E. Content Screening Gateways

🟢 OFFICIAL SYLLABUS LEVEL 2 – EXAM LEVEL

E.1 Definition and purpose

Definition

A content screening gateway is a security device or service placed between users and the Internet that inspects the content of web pages, emails and files and blocks harmful, inappropriate or policy-violating content.

Hinglish

Firewall dekhta hai "kaun aa raha hai" (IP, port). Content gateway dekhta hai "kya aa raha hai" (website, email, attachment ke andar kya hai). Jaise airport par bag ke andar ka saman scan hota hai.

Purpose: stop malware, block unsafe/adult sites, stop spam and phishing, prevent data leakage, save bandwidth, enforce Internet usage policy.

E.2 How it works (step by step)

  1. User opens a website or receives an email. The request goes through the gateway.
  2. Gateway checks URL / domain against category and reputation lists.
  3. If allowed, it downloads the content and scans it (antivirus, keywords, file type).
  4. Spam, phishing, malware or policy violation is blocked or quarantined.
  5. Clean content is delivered to the user.
  6. All actions are logged and reports are generated.

Diagram 6: Content screening gateway filtering Internet access

Explanation: All web and email requests pass through the gateway. It checks URL, content and attachments. Harmful items are blocked; safe content is allowed.

Hinglish

Student, staff aur mail, sab ki request gateway se guzarti hai. Gateway URL, content aur attachment check karta hai. Kharab cheez block hoti hai, achhi cheez jaati hai.

Definition

DLP is a security method that detects and stops sensitive data (like card numbers, ID numbers, confidential files) from leaving the organization through email, web upload or USB.

Hinglish

Content gateway sirf andar aane wale kharab content ko hi nahi, balki bahar jaane wale important data ko bhi check kar sakta hai. Isi ko DLP kehte hain.

E.5 Advantages, disadvantages and limitations

✔ Advantages
  • Blocks malware and phishing
  • Enforces Internet policy
  • Saves bandwidth and improves productivity
  • Protects children/students from unsafe content
  • Gives usage reports

  • Can block safe sites by mistake (false positive)
  • Cannot inspect HTTPS without SSL inspection
  • Smart users may bypass using VPN/proxy
  • Privacy concerns, needs policy
  • Needs constant database updates

NGFW – Next-Generation Firewall (Advanced Detail)

🔵 EXTRA KNOWLEDGE — NOT EXPLICITLY MENTIONED IN SYLLABUS LEVEL 3
Definition

NGFW is a firewall that combines stateful inspection with deep packet inspection (DPI), application awareness, user identity control, integrated IPS, malware protection, SSL/TLS inspection and threat intelligence in one platform.

Hinglish

Purana firewall bolta hai "port 443 allowed". NGFW bolta hai "port 443 allowed hai, lekin isme YouTube nahi chalega, Facebook chat band hai, aur is user ko hi Gmail allowed hai." Yaani wo application aur user dono pehchanta hai.

Main features

  • Application awareness: identifies apps (WhatsApp, Torrent, Zoom) even on the same port.
  • User identity: rules by user or group (connected with Active Directory), not only by IP.
  • Integrated IPS: blocks exploits.
  • Deep packet inspection: reads packet payload.
  • SSL/TLS inspection: decrypts, checks and re-encrypts HTTPS traffic.
  • Sandboxing and threat intelligence: tests unknown files in a safe area; uses online lists of bad IPs/domains.

SSL/TLS inspection – how it works

  1. User opens an HTTPS site; NGFW acts as a middleman.
  2. NGFW decrypts the traffic using its own trusted certificate.
  3. Traffic is scanned by IPS, antivirus and filters.
  4. NGFW re-encrypts it and sends it to the server or user.
Note: SSL inspection has privacy and legal issues. Banking and health sites are usually excluded from inspection.
✔ Advantages
  • One device, many protections
  • Controls applications and users
  • Detects hidden threats in HTTPS
✖ Disadvantages
  • Costly, needs licences
  • Needs powerful hardware
  • SSL inspection slows traffic

Examples: Palo Alto Networks, Fortinet FortiGate, Cisco Firepower, Check Point.

3-5 marks

Q. What is NGFW? Write its features.
NGFW is an advanced firewall that adds application awareness, user identity control, integrated IPS, deep packet inspection, SSL inspection and threat intelligence to normal stateful firewall functions.

Keywords: DPI, application awareness, user identity, SSL inspection, sandbox, threat intelligence.

UTM – Unified Threat Management

🔵 EXTRA KNOWLEDGE — NOT EXPLICITLY MENTIONED IN SYLLABUS LEVEL 3
Definition

UTM is a single security appliance that combines many security functions such as firewall, IDS/IPS, antivirus, VPN, web filtering and anti-spam in one box with one management console.

Hinglish

UTM "sab kuch ek mein" device hai. Chhote office ke liye alag-alag 5 device kharidne ki jagah ek hi device sab kaam kar deta hai. Sasta aur manage karna aasan.

Example

A small coaching institute with 40 PCs uses one UTM box for firewall, VPN, web filtering and antivirus instead of buying four devices.

✔ Advantages
  • Low cost, easy management
  • One vendor, one dashboard
  • Good for small/medium business
✖ Disadvantages
  • Single point of failure
  • Performance drops when all features are on
  • Less powerful than separate specialist devices

Examples: Sophos XG, Fortinet FortiGate, WatchGuard, SonicWall.

3 marks

Q. What is UTM?
UTM is an all-in-one security device that provides firewall, IDS/IPS, antivirus, VPN, web filtering and spam filtering together, managed from one console. It is mostly used in small and medium organizations.

SWG – Secure Web Gateway

🔵 EXTRA KNOWLEDGE — NOT EXPLICITLY MENTIONED IN SYLLABUS LEVEL 3
Definition

A Secure Web Gateway is a security solution (appliance or cloud service) that filters Internet traffic of users, enforces web policy, blocks malicious websites and scans downloads for malware.

Hinglish

SWG ek specialist content gateway hai jo sirf web browsing ko safe rakhta hai: bure sites block, download scan, aur HTTPS check.

Features: URL filtering, malware scanning, SSL inspection, application control, DLP, user-based policy. Examples: Zscaler, Cisco Secure Web Appliance, Forcepoint. Relation to syllabus: it is a modern form of the content screening gateway (Topic E).

Email Security Gateway

🔵 EXTRA KNOWLEDGE — NOT EXPLICITLY MENTIONED IN SYLLABUS LEVEL 3
Definition

An email security gateway is a filter placed in front of the mail server that scans incoming and outgoing email for spam, phishing, malware and sensitive data.

Hinglish

Ye mail server ke aage baitha chowkidaar hai. Fake bank mail (phishing), spam aur virus wale attachment ko andar aane se pehle hi pakad leta hai.

How it works: mail arrives → sender checks (SPF, DKIM, DMARC) → spam score → attachment and link scan (sandbox) → deliver, quarantine or reject. Examples: Proofpoint, Mimecast, Cisco Secure Email.

Relation to syllabus: it is the email part of content screening gateways (Topic E).

WAF – Web Application Firewall

🔵 EXTRA KNOWLEDGE — NOT EXPLICITLY MENTIONED IN SYLLABUS LEVEL 3
Definition

A WAF is a firewall that protects web applications and websites by filtering and monitoring HTTP/HTTPS requests, blocking attacks such as SQL injection and cross-site scripting (XSS).

Hinglish

Normal firewall port aur IP dekhta hai. WAF website ke request ke andar ka text dekhta hai, jaise login box mein koi hacker SQL command to nahi daal raha. Online shopping website ko isse bachate hain.

Example

E-commerce site: an attacker types ' OR 1=1 -- in the login box. WAF detects the SQL injection pattern and blocks the request.

Examples: Cloudflare WAF, AWS WAF, ModSecurity (open source), F5. Difference: Network firewall protects the network (Layers 3-4); WAF protects web applications (Layer 7).

NAC – Network Access Control

🔵 EXTRA KNOWLEDGE — NOT EXPLICITLY MENTIONED IN SYLLABUS LEVEL 3
Definition

NAC is a security solution that decides which devices and users are allowed to connect to the network, after checking their identity and security health (antivirus, updates).

Hinglish

NAC network ke gate par "ID card aur health check" jaisa hai. Koi bhi laptop plug karega to pehle check hoga: kaun hai, antivirus update hai ya nahi. Fail hua to guest ya quarantine network mein bhej diya jaata hai.

Steps: device connects → identify (802.1X, certificate, MAC) → health check → allow, restrict or quarantine. Example: a visitor's laptop with no antivirus gets only guest Internet, not the college server.

SIEM – Security Information and Event Management

🔵 EXTRA KNOWLEDGE — NOT EXPLICITLY MENTIONED IN SYLLABUS LEVEL 3
Definition

SIEM is a system that collects logs and alerts from firewalls, IDS/IPS, servers and other devices in one place, correlates them, and raises alerts about possible security incidents.

Hinglish

Firewall, IDS, server sab apne-apne log banate hain. SIEM sab logs ko ek jagah jama karke jodta hai. Jaise bank ke saare CCTV ka ek control room. Isse admin ko poori tasveer milti hai.

Example of correlation

Firewall log: many failed logins from one IP. IDS: port scan from same IP. Server log: successful login from same IP at 3 AM. SIEM joins these and raises one high-priority alert: "Possible brute-force attack succeeded".

Functions: log collection, correlation, alerting, dashboards, reports, compliance. Examples: Splunk, IBM QRadar, Microsoft Sentinel, Wazuh. IDS/IPS alerts are normally sent to SIEM.

Zero Trust Security – Basic Introduction

🔵 EXTRA KNOWLEDGE — NOT EXPLICITLY MENTIONED IN SYLLABUS LEVEL 3
Definition

Zero Trust is a security model based on the idea "never trust, always verify". No user or device is trusted automatically, even if it is inside the company network. Every access request is verified.

Hinglish

Purana model: "andar wale sab bharosemand". Zero Trust: "andar ho ya bahar, har baar pehchaan aur permission check karo." Jaise office mein har room ke liye alag swipe card.

  • Verify explicitly: check user, device health and location every time.
  • Least privilege: give only the minimum access.
  • Assume breach: design as if attacker is already inside.
  • Micro-segmentation: divide network into small zones so an attacker cannot move freely.

Why important: remote work, cloud and mobile devices mean the old "perimeter" firewall alone is not enough. VPN is slowly being replaced by Zero Trust Network Access (ZTNA) in many companies.

Real organizations do not use one device. They use Defense in Depth: many layers, so if one layer fails, the next one still protects.

Hinglish

Ghar ki suraksha ki tarah: boundary wall, gate, darwaza, almari ka lock. Ek fail ho to doosra bachata hai. Network mein bhi firewall, IPS, VPN, content gateway, sab milkar kaam karte hain.

Diagram 7: Integrated network security architecture

Explanation: Internet traffic first meets the perimeter firewall. IPS blocks attacks. Public servers sit in the DMZ. Remote users enter through the VPN concentrator. Web and email pass through the content gateway. IDS sensors and SIEM watch everything and collect logs.

Pehle firewall, phir IPS, public servers DMZ mein, remote log VPN se, web/mail content gateway se. IDS aur SIEM sab par nazar rakhte hain. Ye sab milkar poori suraksha dete hain.

IDS/IPS integration

IDS and IPS are often combined (IDPS). Many NGFWs include IPS. IDS sensors send alerts to SIEM, the SOC (Security Operations Centre) team investigates, and IPS rules are tuned to block repeated attacks.

Practical industry applications

  • Banks: NGFW + IPS + WAF + SIEM + VPN for staff.
  • Colleges: UTM or NGFW with web filter.
  • E-commerce: WAF + DDoS protection + IPS.
  • IT companies: VPN/ZTNA + SWG + email gateway + SIEM.

Important definitions (copy and memorize)

Firewall

A hardware or software security system that monitors network traffic and allows or blocks it according to predefined security rules.

IDS

A tool that monitors network or host activity, detects suspicious behaviour and sends alerts. It does not block traffic.

IPS

An in-line security device that inspects traffic and automatically blocks malicious activity in real time.

VPN

A technology that creates a secure encrypted tunnel over a public network such as the Internet.

VPN Concentrator

A dedicated device that creates and manages many VPN tunnels at once and handles encryption and authentication of remote users or sites.

Content Screening Gateway

A device between users and the Internet that inspects web, email and file content and blocks harmful or unwanted content.

DMZ

A separate network zone between the Internet and internal LAN, used for public-facing servers.

One-page summary

  • Firewall types: Packet filter, Stateful, Application/Proxy, Circuit-level, NGFW.
  • Firewall working: read packet → match rules top to bottom → allow/deny → default deny → log.
  • IDS: passive, gets a copy, detects + alerts. Types: NIDS, HIDS. Methods: signature, anomaly.
  • IPS: active, in-line, detects + blocks. Types: NIPS, HIPS. Actions: drop, block IP, reset, rate limit.
  • VPN concentrator: authenticate → negotiate keys → tunnel → encrypt/decrypt. Types: remote-access, site-to-site. Protocols: IPsec, SSL/TLS.
  • Content gateway: web filter, URL filter, email filter, spam filter, malware scan, content inspection, DLP.
  • Extra: NGFW, UTM, SWG, Email gateway, WAF, NAC, SIEM, Zero Trust.
